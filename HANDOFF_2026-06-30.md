## 7. Workflow architecture

Single-pass flow:

```
UNETLoader High → SVI LoRA (0.7) → LightX2V LoRA (0.7) → ModelSamplingSD3 (shift=8) → KSampler High (0→4)
UNETLoader Low  → SVI LoRA (0.7) → LightX2V LoRA (0.7) → ModelSamplingSD3 (shift=8) → KSampler Low  (4→∞)

CLIPLoader → CLIPTextEncode (pos / neg)
VAELoader  → VAEEncode (anchor)
LoadImage  → ImageScale (512px) → VAEEncode

WanImageToVideoSVIPro (anchor, length=97, prev_samples=none)
   → KSampler High → KSampler Low → VAEDecode
        → Render                (16fps)
        → RIFE 2×  → Render-rife (32fps)
        → RealESRGAN 4× → Render-upscaled       (16fps)
        → RIFE 2× → RealESRGAN 4× → Render-rife-upscaled (32fps)
```
